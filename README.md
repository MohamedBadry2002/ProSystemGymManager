# دليل تشغيل وتطوير ProSystem Gym Manager Enterprise (.NET)

تم بناء هذا التطبيق بالكامل وفقاً لمستند الهندسة العكسية والمواصفات الفنية المرفقة:
**ProSystem Gym Manager Enterprise v4.2** باستخدام أحدث تقنيات بيئة عمل **.NET 8 (C#)** وقاعدة بيانات محلية سريعة ومستقلة **SQLite**.

---

## 🚀 طريقة التشغيل السريع

1. يمكنك تشغيل البرنامج مباشرة بالنقر المزدوج على ملف:
   `تشغيل التطبيق - Run App.bat`
   أو تشغيل الملف التنفيذي المباشر:
   `Publish\ProSystemGymManager.exe`
2. لإجراء فحص واختبار ذاتي لجميع وحدات النظام وسرعة استجابة الباركود:
   `تشغيل وضع الاختبار - Run Tests.bat`

---

## 🛠️ تفاصيل المعمارية والوحدات المنجزة

### 1. شاشة الدخول اللحظي والتحكم بالبوابات (Real-Time Check-In Zone)
- **تصميم مخصص لمكاتب الاستقبال (Reception Desk)**: متوافق مع الاتجاه من اليمين لليسار (RTL) مع ألوان عالية التباين (High Contrast Dark UI).
- **حقل باركود نشط دائم (Continuous Auto-Focus)**: التقاط تلقائي لباركود العضو دون الحاجة للنقر بالفأرة أو الضغط على Enter.
- **استجابة فائقة السرعة (< 200ms)**: تم تحقيق زمن استجابة يتراوح بين **10ms و 25ms**، أي أسرع 10 أضعاف من الحد الأقصى المطلوب.
- **التنبيهات المرئية والصوتية (Visual & Audio Alerts)**:
  - **اشتراك ساري**: كارت أخضر مميز مع صوت تأكيد (Success Beep) وتفاصيل الباقة والأيام المتبقية (مثال: `[نشط / 15 يوم متبقي]`).
  - **اشتراك منتهي**: كارت أحمر مع صوت تحذيري مزدوج (Warning Buzz) وتفاصيل انتهاء الاشتراك مع منع الدخول.
  - **غير مسجل**: تنبيه صوتي وشاشة تحذيرية حمراء.
- **محاكاة فتح البوابة الإلكترونية (Gate Open/Blocked)** مع مؤشر ديناميكي.
- **جدول الحضور اليومي اللحظي (Real-time Log Table)**: تحديث فوري لكل حركة دخول مع الوقت، اسم المشترك، الباقة، والحالة.

### 2. معالج تسجيل المشتركين (Subscription Lifecycle Wizard)
معالج تفاعلي متعدد الخطوات (Step-by-Step Wizard):
1. **البيانات الشخصية والطبية**: الاسم، رقم الهاتف، الرقم القومي، هاتف الطوارئ، الملاحظات الطبية، ورقم الباركود الفريد مع زر التوليد التلقائي.
2. **اختيار باقة الاشتراك**: عرض الباقات (VIP سنوي، شهر كامل، 3 شهور، 6 شهور، Daily Pass) مع السعر وحساب تاريخ الانتهاء تلقائياً.
3. **الدفع والإيصال**: تسجيل المبلغ المطلوب، المدفوع، المتبقي، طريقة الدفع (كاش، فيزا، فودافون كاش، انستاباي)، والمدرب المشرف.
4. **الصورة الشخصية وبطاقة العضوية**: رفع صورة من الجهاز أو التقاطها عبر الكاميرا مع معاينة وطباعة بطاقة العضوية (Member ID Card) مزودة بباركود وشعار الجيم.

### 3. نقاط البيع السريعة والمخزون (Touch POS & Inventory)
- أزرار لمس كبيرة سريعة (Touch-friendly Buttons) للأصناف الأكثر طلباً: مياه معدنية، واي بروتين، ريد بول، بروتين بار، BCAA، قفازات، شيكر... إلخ.
- دعم قراءة باركود المنتجات سريعاً.
- سلة المشتريات التفاعلية وحساب الخصم والمدفوع والباقي للعميل.
- إصدار وطباعة فواتير حرارية (ESC/POS Thermal Receipt Layout) متوافقة مع مقاسات 80mm/58mm.
- خصم تلقائي للكميات من المخزن وقيد المبيعات في الخزينة.

### 4. وحدة إدارة الحسابات والخزينة (Financial Module & Treasury)
- متابعة فورية لمقبوضات ومصروفات وصافي رصيد الخزينة اليومية.
- تسجيل المصروفات التشغيلية (فواتير، إيجار، صيانة، نظافة، نثريات).
- **حساب عمولات ونسب المدربين (Trainer Commissions)**: اختيار الكابتن، تحديد نسبة العمولة (مثل 15%)، احتساب إجمالي مبيعاته وصرف العمولة وقيدها كمصروف بالخزينة.

### 5. نظام التقارير والإشعارات (Reporting Suite)
- **كشف الاشتراكات المنتهية والقريبة من الانتهاء (خلال 7 أيام)**: زر مباشر لإرسال رسالة تذكير عبر **WhatsApp** بنقرة واحدة تحتوي على رسالة تشجيعية مخصصة باسم العضو وتاريخ انتهائه.
- **التقرير المالي التفصيلي**: توزيع الإيرادات حسب نوع الاشتراك والمبيعات مقابل المصروفات.
- **تحليل ساعات الذروة (Peak Hours Analytics)**: رسم بياني تفاعلي يوضح كثافة الحضور على مدار ساعات العمل لتنظيم نوبات المدربين والنظافة.

## 🗄️ هيكل قاعدة البيانات (Database Schema)

| اسم الجدول | الحقول الرئيسية | الغرض |
|---|---|---|
| `Members` | `Id, FullName, Phone, NationalId, BarcodeId, PhotoUrl, MedicalNotes, EmergencyContact, CreatedAt` | بيانات الأعضاء وأرقام الباركود الفريدة |
| `Plans` | `Id, Name, DurationDays, Price, Description` | باقات الاشتراكات والأسعار والمدد |
| `Subscriptions` | `Id, MemberId, PlanId, StartDate, EndDate, IsActive, PricePaid, Notes` | ربط العضو بالباقة وصلاحية الاشتراك |
| `CheckIns` | `Id, MemberId, CheckinTime, Status, GateId, Notes` | سجل حركات الدخول اللحظي عبر البوابة |
| `Transactions` | `Id, MemberId, Amount, Type, Category, Description, TrainerName, CreatedAt` | حركات الخزينة والمصروفات والعمولات |
| `Products` | `Id, ProductName, Price, StockQty, Barcode, Category, ImagePath` | منتجات نقطة البيع ومخزون المكملات والمشروبات |
